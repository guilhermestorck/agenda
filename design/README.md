# Design

SVG mockups of agenda's screens, for editing in Penpot.

Generated by `scripts/make-design.py` rather than drawn by hand, so when the implementation
moves they can be regenerated instead of redrawn. They describe the app as built: the
view-only sidebar, the span switcher, compressed quiet hours, the reminder lead-in bands.

## Round trip

1. Penpot runs from `~/workspace/personal/penpot` — `docker compose up -d`, then
   http://localhost:9001. **It has no account yet**; registering one is yours to do, since
   it means choosing a password.
2. In a project, **Import** each SVG. Penpot turns them into editable shapes rather than a
   flat image.
3. Edit by hand.
4. Export the board back to SVG into this directory, keeping the file name, and say so —
   the diff against the generated version is the design change to implement.

Keep the generated files under their original names so the diff stays readable. If a screen
changes shape enough that regenerating would clobber your edits, rename your version with a
`-v2` suffix and we will reconcile.

| File | Screen |
|---|---|
| `01-week.svg` | Week grid — the default view |
| `02-month.svg` | Month grid with `+N more` overflow |
| `03-agenda.svg` | Agenda list |
| `04-preferences-settings.svg` | Preferences → Settings |
